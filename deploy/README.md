# Deploy

Reference deployment assets for The Peaks Factory.

- `releases/` contains the immutable release-manifest contract and structural example;
- `vds/` contains target same-host systemd/nginx/environment guidance;
- production history, credentials, receipts, backups, and rollback evidence are not published.

See [`../docs/DEPLOYMENT.md`](../docs/DEPLOYMENT.md). These files are examples and contracts; their presence
does not authorize installation or a production change.
