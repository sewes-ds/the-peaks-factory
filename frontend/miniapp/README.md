# Telegram Mini App

Production React/Vite Telegram Mini App implementing the project graph runtime and Sections 01-04.
Section 04 is currently an explicit access-boundary placeholder, not a completed Director cabinet.

Use the package scripts in `package.json` for tests, type checking, contract verification, browser gates,
and production builds. Project-wide architecture is documented in
[`../../docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md).
