# Mini App Icons

Canonical runtime icon directory:

`frontend/miniapp/public/assets/icons/`

Rules:

1. Shared action icons are stored directly in this directory, not inside section-specific folders.
2. Icons are named by action meaning, not by screen or section.
3. Keep filenames stable; replace SVG contents when final icons are ready.
4. Button icon viewport/box is 45×45 px.
5. Current files are placeholders: transparent 45×45 SVG with one center dot in the intended button fill color.
6. Do not duplicate common icons such as `back.svg` per section.
