# Security policy

## Supported version

Only the current `main` branch is reviewed for security reports. Historical internal revisions are not
published or supported.

## Reporting a vulnerability

Use GitHub's **Security → Report a vulnerability** private reporting flow for this repository. Do not open
a public issue and do not attach credentials, raw Telegram data, database dumps, QR tokens, employee data,
or production logs to an issue or pull request.

Include a concise description, affected component, reproduction conditions, likely impact, and a proposed
remediation if known. Use synthetic data and reserved example domains.

The repository contains no bug-bounty promise and no authorization to test a production system. Source
review does not authorize access to infrastructure, accounts, bots, users, or data.
