# Contributions

This repository is published for inspection and technical review. It is not an open-source project and
does not currently accept unsolicited code, documentation, design, or data contributions.

- Pull requests may be closed without review.
- Do not submit confidential information, personal data, credentials, QR values, production logs, or
  proprietary material.
- Do not use a public issue for a suspected vulnerability. Follow [SECURITY.md](SECURITY.md).

Publication of the source and discussion of it do not grant rights beyond [LICENSE](LICENSE).
